# Food Delivery App

A menu-driven, command-line food delivery app built with Python. Browse restaurants and menus, search or filter dishes, manage a cart, apply coupons, place orders, and review order history.

## Features

- Browse and select from three restaurants
- View restaurant menus
- Search for a dish by name
- Filter menu items by maximum price or food type
- Add dishes to the cart and update quantities
- Remove dishes and view the cart
- Apply discount coupons
- Check out and view past orders

## Restaurants

| ID | Restaurant | Sample dishes |
|---:|---|---|
| 101 | Biryani House | Chicken Biryani, Mutton Biryani, Veg Biryani |
| 102 | Pizza Corner | Margherita Pizza, Chicken Pizza, Paneer Pizza |
| 103 | Green Leaf Restaurant | Veg Meals, Paneer Fried Rice, Mushroom Noodles |

Prices are shown in Indian rupees (₹).

## Requirements

- Python 3
- No external packages required

## Run the app

1. Save the code to a file, such as `food_delivery.py`.
2. Open a terminal in the folder containing the file.
3. Run:

   ```bash
   python food_delivery.py
